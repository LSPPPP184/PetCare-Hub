Điều gì giống nhau trong cả ba hướng?

Cùng dữ liệu, cùng trạng thái nghiệp vụ, cùng chức năng lọc và 5 trang bấm qua lại. Mỗi hướng có bố cục, phông chữ, hình khối và màu thương hiệu riêng để so sánh công bằng.
